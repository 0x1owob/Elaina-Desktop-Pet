# 伊蕾娜桌寵 · macOS

目前版本 **2.2.1／build12**。使用 Swift 與 AppKit，包含 Apple Silicon／Intel 通用執行檔，最低部署目標為 macOS 12。

## 操作

| 操作 | 行為 |
| --- | --- |
| 單擊 | 短暫回應；等待系統雙擊間隔後顯示 |
| 按住 0.25 秒或移動超過 4pt | 抓起角色，雙手扶帽並隨移動輕微搖晃 |
| 放開 | 短暫下落與整理姿態，可立即再抓取 |
| 雙擊 | 無台詞騎掃帚飛往同螢幕的新落點，完成後停留 |
| 全螢幕 | 飛离畫面；結束後返回 |
| 右鍵／選單列 ✦ | 開啟互動、行為、外觀與活動控制 |

中型角色為 **105pt**，另有 77pt／138pt。雙擊短飛目標為角色高度的四倍，中型空間足夠時約 420pt；慢／一般／快分別約 1.6／1.2／0.8 秒，邊界空間不足會縮短航程。全螢幕離場／返回分別沿用 1.2／0.9／0.6 秒速度。

連續抓取三次會短暫不耐煩；最後放下後 15 秒未再抓取會重置連抓狀態。長按超過三秒的反應與環境打擾另計。

## 安靜陪伴

- 初見問候一次，平時不主動找使用者聊天。
- 內心戲每輪等待 200–400 秒正常可見活動，安全停步時顯示，最多四秒。
- 自動麵包每輪累積五分鐘正常可見活動；十格動畫約八秒，麵包逐漸吃完。
- 隱藏、暫停、睡眠與全螢幕期間不補播事件或對話。
- 「互動 → 測試吃麵包／測試內心戲」可以立即查看演出。

## 外觀與台詞

「外觀 → 對話框透明度」調整背景與邊框不透明度 **20–100%**，預設 60%，設定會保存。文字保持不透明，使用 12pt Cubic 11 像素字體，沒有描邊或陰影；缺字由 macOS 字型替代。深色背景搭配低不透明度時，可提高背景不透明度改善閱讀。

透過「互動 → 修改台詞…」編輯 `~/Documents/Codex/ElainaDesktopPet/dialogues.json`。支援 `greetings`、`jump`、`innerThoughts` 與帶權重的 `clickResponses`。程式會補齊缺少欄位並保留既有內容；更新前建立備份，損壞的 JSON 不會被覆寫。

## 建置

在此資料夾執行：

```sh
bash build.sh
```

產生 `Elaina.app`，包含通用主程式、通知輔助程式、角色素材及字型授權，採 ad hoc 簽章。正常建置會執行素材、幾何、通知、行為與字體檢查；`bash build.sh --skip-self-test` 僅建置。

發布包目前尚未經 Apple Developer ID 簽署與公證。macOS 首次開啟可能受到限制，請參閱 [Apple 官方說明](https://support.apple.com/zh-tw/102445)。

## 本機 Codex 反應

此項整合為選用功能。`install_codex_notify.py` 可檢查、安裝或恢復本機 notify 設定，保留原有 callback，需 Python 3.11 或更新版本。請先執行 `python3 install_codex_notify.py preview` 檢查設定，再依需要執行 `install`。

有效的本機 `agent-turn-complete` 事件可觸發無聲轉向或短暫不耐煩；不代表判定任務成功。未接入手機、ChatGPT 網頁、雲端任務或其他 App 的通知內容。

## 相容性與限制

全螢幕判斷依所在螢幕與前景視窗範圍推測；部分無邊框視窗或多螢幕切換可能誤判。動畫組間仍有少量輪廓差異。Intel／macOS 12 已包含編譯目標，尚未完成對應硬體測試。

測試證據與目前範圍見 [測試與相容性](../docs/VERIFICATION.md)。
