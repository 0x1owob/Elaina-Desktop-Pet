# Elaina Desktop Pet


**讓旅途，暫時停在你的桌面。**

Elaina Studio 製作的 macOS 像素桌面寵物，以《魔女之旅》的伊蕾娜為主題。一位有自己步調的魔女，今天決定在你的桌面上稍作停留。

> 「這裡倒是個適合歇腳的地方。那麼，容我暫住一會兒吧。」


## 和魔女共度的日常

你忙著自己的事，她也有她的安排。在桌面上散散步，餓了就拿出麵包，慢慢吃完。偶爾停下來想些事情，至於今天的自己是否依然可愛——她大概早已有了答案。

想和她打個招呼，可以輕輕點她一下。如果把她拎起來，她會趕緊用雙手扶好帽子，隨你的動作輕輕搖晃。放回桌面後，還得整理一下儀容。至於接連被抓起來這件事，她可不一定會一直保持好脾氣。

輕點兩下，她便騎上掃帚，飛到桌面的另一處落腳。當你開啟全螢幕看影片或做自己的事，她也會暫時出門，等你回到桌面，再悠悠地飛回來。

大多數時候，她只是安靜地待在那裡。你可以偶爾看看她，也可以各自忙碌，讓一天裡多出幾個不經意的小片刻。


## 請她來歇歇腳

從 [版本發佈頁](https://github.com/0x1owob/Elaina-Desktop-Pet/releases/latest) 下載 macOS 版本。需要 **macOS 12 或以上**，支援 Apple Silicon 與 Intel。

1. 下載 ZIP 並解壓縮。
2. 將 `Elaina.app` 放入「應用程式」資料夾後開啟。
3. 從選單列 **✦** 或角色右鍵選單，調整她在桌面上的大小、步調與對話框透明度。

目前版本尚未經 Apple Developer ID 簽署與公證，macOS 可能阻擋首次開啟。遇到提示時，請參閱 [Apple 官方說明](https://support.apple.com/zh-tw/102445)。

更多操作方式與台詞編輯說明，請見 [使用指南](app/README.md)。


## 旅途仍在繼續

目前版本持續打磨動作的自然度、角色的一致性與日常相處的感覺。部分動作交接仍有造型差異，多螢幕與部分無邊框視窗的全螢幕判斷也可能不準確；完整測試範圍見 [測試與相容性](docs/VERIFICATION.md)。Windows 版本為後續方向。

想了解專案或參與開發，可以從 [開發指引](CONTRIBUTING.md)、[技術結構](docs/ARCHITECTURE.md) 與 [美術素材](Artwork/README.md) 開始。

由 **Elaina Studio** 製作與維護。像素字體採用 Cubic 11，完整授權收錄於 [字型授權](app/Assets/Fonts/OFL.txt)。
