# 測試與相容性

目前發行版本 **2.2.1／build12**，以最後檢查完成的通用 App 打包。

## 已執行

- 完整建置包含素材自檢、既有幾何／通知／行為回歸及 85 項文字檢查。
- 主程式与通知輔助程式皆包含 arm64／x86_64，Info.plist 與 strict deep 簽章檢查通過。
- 31 張正式 PNG、字型與完整授權檔逐 byte 核對；42 份 App bundle 檔案保留凍結雜湊。
- 短飛的三檔時間、三種大小航程、负座標、狹窄螢幕与安全落點檢查通過。
- 四句內心戲與內建台詞字形存在；稀有中文及常見 emoji 以原生字型替代，實際文字 frame 不截斷測試內容。
- 1x／2x 明暗背景與 20／60／100% 不透明度的原生泡泡繪圖預覽已查看。
- 本機實機確認雙擊短飛與停留、像素泡泡無白邊／截字／遮臉、途中再抓取與全螢幕進退。
- 發行 ZIP 解壓後的 42 份 App 檔案逐一匹配原 bundle，簽章及封裝後素材自檢通過。

## 尚未涵蓋

Intel 與 macOS 12 實機、全部多螢幕／睡眠情境、長時間穩定性與實際跨 App 通知送達尚未完成完整測試。1x／2x 為離線原生繪圖，不能推定兩種顯示器皆已實測。

目前採 ad hoc 簽章，尚未經 Apple Developer ID 簽署與公證。完整測試不代表 Apple 安全驗證。

深色桌面搭配低泡泡背景不透明度時可能較難閱讀；既有透明度滑塊可調。動畫輪廓銜接仍有差異，部分全螢幕偵測情境可能不準確。
