# 素材與來源

## 角色與像素美術

本作是以白石定規《魔女之旅》的伊蕾娜為主題的非官方同人專案，角色與原作插畫設計相關權利屬於原權利人；原作插畫為あずーる。原作資訊可見 [GA Novel／SB Creative](https://www.sbcr.jp/product/4797384352/)。

像素美術以專案提供的伊蕾娜像素主視覺及角色參考為基礎，使用 OpenAI 圖片生成工具協助製作，再進行透明背景、逐幀整理、對齊、色彩與局部像素修整。這些素材不宣稱為官方美術，也不另授予角色或插畫的權利。

`app/Assets/` 包含實際執行的角色 PNG、圖示、台詞與動畫 JSON。`Artwork/Library/` 僅收錄用於作品介紹的透明動畫。開場介紹與桌寵台詞為本專案撰寫，並非摘錄原作。
