# 美術素材

伊蕾娜在桌面上的站姿、散步、抓取、飛行與吃麵包演出，使用透明 PNG 與隨附的動畫設定。執行所需的正式素材集中於 [app/Assets](../app/Assets/)。

此處保留掃帚、步行與麵包的透明展示動畫，供作品介紹使用。麵包展示是四格循環；App 內使用十格逐漸吃完的版本。

| 路徑 | 內容 |
| --- | --- |
| Library/broom/broom-preview.gif | 騎掃帚展示 |
| Library/idle-walk/Walking-preview.gif | 散步展示 |
| Library/bread-reference/bread-preview.gif | 吃麵包展示 |
| SOURCES.md | 角色、美術製作與字型來源說明 |
| inventory.json | 本資料夾展示素材的 SHA-256 |

新增或替換素材時，請檢查透明背景、畫布、角色比例、幀順序與動作銜接，再更新正式 PNG 與動畫設定。預覽 GIF 不參與 App 播放。
